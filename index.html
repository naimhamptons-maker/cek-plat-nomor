Pengaturan Sinkronisasi & Import Data

Data tersimpan otomatis di memori HP agar tetap bisa dibuka Offline

1. Auto-Sync Google Sheets (Saat Online)

Saat HP terhubung internet, aplikasi otomatis menarik pembaruan dari Google Sheets dan menyimpannya ke memori offline perangkat.

Lihat Kode Google Apps Script 
function doGet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheetNames = ['TOWER A', 'TOWER B', 'TOWER C', 'TOWER D', 'Data Parkir'];
  var result = {};
  sheetNames.forEach(function(name) {
    var sheet = ss.getSheetByName(name);
    if (sheet) {
      result[name] = sheet.getDataRange().getDisplayValues();
    }
  });
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}
